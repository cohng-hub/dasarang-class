# 📖 내 그림이 이야기 속으로! - 나만의 그림책 만들기

유치원 부모참여수업을 위한 **‘나만의 그림책 만들기’** 웹 애플리케이션입니다.  
어린이가 도화지에 직접 그린 손그림을 촬영하여 올리고, 부모님과 대화를 나누며 이야기를 만들면,  
어린이가 그린 그림 속 캐릭터가 살아 숨 쉬는 아름다운 **6페이지 동화책(표지 1장 + 본문 5장)**이 완성됩니다.

---

## 🌟 주요 특징 및 기능

### 1. 아이의 손그림을 100% 소중하게 보존
- AI가 캐릭터를 멋대로 새로 그리지 않고, **아이가 그린 크레파스/색연필의 선, 색칠, 삐뚤빼뚤한 형태**를 그대로 유지합니다.
- **스마트 배경 투명화 엔진**: 흰 도화지/스케치북 배경만 투명하게 지우고, 캐릭터에 사랑스러운 동화책 스티커 테두리와 그림자를 둘러 어떤 장면에도 자연스럽게 어우러집니다.
- 촬영된 그림이 없더라도 즉시 수업에 참여할 수 있도록 **3종 크레용 손그림 샘플(분홍 토끼 몽실이, 아기공룡 또또, 꼬마별 퐁이)**을 제공합니다.

### 2. 부모참여수업 맞춤형 대화형 이야기 만들기
- **1단계 질문 모드**:
  1. *주인공은 어디에 갔나요?*
  2. *누구를 만났나요?*
  3. *어떤 일이 일어났나요?*
  4. *주인공은 무엇을 했나요?*
  5. *이야기는 어떻게 끝났나요?*
- 어린이가 손가락으로 콕 짚어 고를 수 있는 **원터치 추천 답변 칩** 제공
- 한 번에 이야기를 자유롭게 작성할 수 있는 **자유롭게 이야기 쓰기** 모드 지원

### 3. 만 4~5세 눈높이 맞춤형 6장면 그림책
- **표지**: 어린이가 지은 제목, 어린이가 그린 주인공 대형 배치, "글·그림: OO이와 엄마" 작가 명패
- **본문 1~5장**: 
  - 신나는 모험의 시작 (출발)
  - 반가운 친구와의 만남
  - 두근두근 신기한 사건
  - 씩씩한 용기와 행동
  - 행복하고 따뜻한 집으로의 귀가
- 리듬감 있는 의성어/의태어가 담긴 1~3문장의 짧고 따뜻한 유아용 동화 이야기

### 4. 실제 책장 넘기기 & 풍성한 인터랙션
- 실제 그림책을 넘기듯 **책장 넘기기 효과음** 및 부드러운 페이지 전환
- **소리내어 읽어주기 (TTS)**: 브라우저 음성 구연동화 기능 탑재
- **이야기 즉석 수정**: 완성 후에도 아이와 함께 문장을 수정할 수 있는 인라인 편집 기능

### 5. 보관 및 인쇄 지원
- **📄 PDF 저장**: A4 가로 규격의 고화질 컬러 PDF 전자책 즉시 다운로드
- **🖼️ 이미지 저장**: 고화질 PNG 이미지 저장
- **🖨️ 인쇄하기**: 부모참여수업 현장에서 바로 출력하여 실물 종이책으로 묶을 수 있는 인쇄 전용 뷰 제공

## 🚀 실행 방법

### 로컬 개발 서버 실행
```bash
# 의존성 설치 (최초 1회)
npm install

# 개발 서버 실행
npm run dev
```
브라우저에서 `http://localhost:5173/`으로 접속하시면 바로 이용하실 수 있습니다.

### 정적 빌드
```bash
npm run build
```
`dist/` 폴더에 생성된 정적 파일들을 웹 호스팅에 바로 배포하실 수 있습니다.
