🌟 유치원 부모참여수업 안내 가이드

1. 활동의 주인공은 아이입니다
아이가 자유롭게 도화지에 크레용으로 그린 소중한 그림을 존중해 주세요. 완벽하게 그리지 않아도 괜찮아요!
2. 스마트 배경 투명화 팁
흰 스케치북이나 종이에 그린 그림을 카메라로 정면에서 촬영하면 그림 주변 종이가 자동으로 투명해져 이야기 속 배경에 쏙 들어갑니다.
3. 대화하며 질문을 던져주세요
"어디에 가고 싶어?", "거기서 누구를 만나볼까?" 아이의 엉뚱하고 기발한 대답을 그대로 적어주시면 멋진 동화책이 탄생합니다.
4. 종이책으로 인쇄해 보세요
완성된 그림책을 [📄 PDF 저장]하거나 [🖨️ 인쇄하기]를 눌러 컬러 출력하면, 아이가 직접 넘겨볼 수 있는 진짜 종이 동화책이 됩니다!

⚙️ Gemini API 및 AI 설정

💡 Gemini API 키 발급 방법 (무료):
1. Google AI Studio 키 발급 페이지에 접속하여 Google 계정으로 로그인합니다.
2. [Create API key] 버튼을 누르면 무료 키가 즉시 생성됩니다.
3. 생성된 키를 복사하여 위 입력창에 넣고 [저장하기]를 누르면 완료!
* API 키를 넣지 않아도 자체 내장된 지능형 동화 엔진으로 고품질 그림책이 100% 무료/오프라인으로 완벽 생성됩니다!
